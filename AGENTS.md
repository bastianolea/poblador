# NA

Datos de población para Chile y utilidades relacionadas

Este paquete ofrece tablas de datos de población oficiales de Chile, así
como funciones para simplificar el uso de estos datos como complemento a
otros conjuntos de datos, por ejemplo, para agregar población oficial a
otras fuentes, calcular tasas de población, entre otros.

Paquete de R en construcción, así que se aceptan opiniones, correcciones
e ideas estratégicas generales

La idea principal es tener varias fuentes de datos con patrones comunes
(codigo_comuna, codigo_region, como en el paquete hermano,
{territorial}), y que esas fuentes se puedan insertar a la función
[`agregar_poblacion()`](https://bastianolea.github.io/poblador/reference/agregar_poblacion.md)
